# Система наёмников

## Установка капитанов

`MercenaryCaptains.xml` — файл точек XMLSpawner2. Он не загружается автоматически только потому, что лежит рядом с C#-скриптами.

1. Убедитесь, что XMLSpawner2 включён и проект скриптов собран.
2. Выполните в игре под администратором `[XmlLoad Scripts/Custom/MercenarySystem/MercenaryCaptains.xml`. Если сервер не находит файл по этому пути, скопируйте его в каталог XMLSpawner2 для спавнов и укажите имя файла.
3. После загрузки точки спавна сохраняются вместе с миром. `XmlLoad` сопоставляет точки по `UniqueId`, поэтому повторный вызов обновляет эти точки вместо создания копий.

Файл создаёт капитанов в городах Trammel. Чтобы поменять размещение, измените `<Map>`, координаты `<X>/<Y>` и высоту `<CentreZ>` в XML, затем снова выполните `XmlLoad`.

## Игровой цикл

- Двойной клик по капитану открывает выкуп павших наёмников, если у аккаунта есть такие записи; из этого меню кнопка «Купить контракт» открывает магазин. Если павших нет, сразу открывается магазин.
- В меню капитана покупается контракт. Двойной клик по контракту из рюкзака призывает выбранный класс наёмника, если хватает слотов контроля.
- Доступные классы определяют боевую специализацию; раса выбирается независимо при создании наёмника.
- Базовая цена контракта первого уровня — 65 000 золотых. Цена растёт на 15% за уровень: второй уровень — 74 750, третий — 85 963. В магазине доступны контракты уровней 1–3 для каждого класса.
- При активации контракта случайно выбираются раса (человек, эльф или гаргулья) и пол наёмника.
- Наёмник получает опыт за убийство существ; цель, уровень и остаток опыта можно посмотреть, использовав EvalInt на наёмнике.
- При гибели принадлежащего игроку наёмника система сохраняет его имя, класс, уровень, опыт, экипировку и рюкзак. Его вещи убираются с трупа, чтобы не получить дубликаты.
- У капитана можно вернуть павшего наёмника за половину стоимости контракта его уровня. Игроку нужны два свободных слота контроля, а золото списывается из банка.
- Список павших сохраняется в `Saves/Custom/MercenaryRescue.bin` при сохранении мира. Старые форматы файла версий 1 и 2 поддерживаются.
